# Password Generator JS Project

This is a **Password Generator** built using **HTML**, **CSS**, and **JavaScript**. The project allows users to generate secure passwords with customizable options. Users can choose the length of the password, select which character types (uppercase, lowercase, numbers, symbols) to include, and view the history of previously generated passwords. Additionally, users can easily copy the generated password to their clipboard with a single click.

## Features

- **Customizable Password Length**: Allows users to choose the desired length of the generated password.
- **Character Type Selection**: Users can select which types of characters to include in the password:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters (symbols)
- **Password History**: Displays a history of generated passwords so users can quickly access past passwords.
- **Copy to Clipboard**: A button that lets users copy the generated password directly to their clipboard for easy use.
- **CSS Styling**: A clean and simple interface with responsive design, making it easy to use on both desktop and mobile devices.
- **JavaScript Functionality**: Dynamically generates passwords based on user-selected options and updates the UI in real time.
