# Random Color Generator JS Project

This is a **Random Color Generator** built using **HTML**, **CSS**, and **JavaScript**. The project allows users to generate random colors in either **HEX** or **RGB** format at the click of a button. This tool is useful for designers, developers, or anyone who needs to quickly generate colors for web projects, UI design, or just for fun.

## Features

- **Random Color Generation**: Generates a random color each time the user clicks the "Generate" button.
- **HEX Color Format**: Displays the generated color in **HEX** format (e.g., #A3B9F0).
- **RGB Color Format**: Displays the generated color in **RGB** format (e.g., rgb(163, 185, 240)).
- **Format Toggle**: Users can choose between **HEX** and **RGB** to see the generated color in their preferred format.
- **Live Color Preview**: The background of the page (or a designated area) changes to the generated color, providing an immediate visual preview of the color.
- **Responsive Design**: The application adjusts to various screen sizes, ensuring a smooth experience on both desktop and mobile devices.
- **CSS Styling**: The app has a clean and modern interface with easy-to-read color codes and a large color preview area.
- **JavaScript Functionality**: Uses JavaScript to generate random values for the color components (RGB or HEX) and update the UI dynamically.
