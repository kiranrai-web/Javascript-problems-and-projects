# Age Calculator JS Project

This is a simple **Age Calculator** built using **HTML**, **CSS**, and **JavaScript**. The project allows users to input their birthdate and calculates their **age** in years, months, and days. It can be useful for various scenarios, such as age verification, age-based recommendations, or just for fun!

## Features

- **Age Calculation**: Calculates the age based on the provided birthdate and today's date.
- **Multiple Units**: Displays the age in **years**, **months**, and **days**.
- **CSS Animations**: Smooth transition and styling for a better user experience.
- **JavaScript Functionality**: Handles the logic of calculating the difference between the user's birthdate and the current date.
- **User-Friendly Input**: Allows users to easily select their birthdate using a date input field.
