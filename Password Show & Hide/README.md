# Password Show and Hide JS Project

This is a simple **Password Show and Hide** functionality built using **HTML**, **CSS**, and **JavaScript**. The project allows users to toggle the visibility of their password input by clicking an eye icon. This functionality provides a better user experience by enabling users to view their password while typing, helping to prevent mistakes during login or account creation.

## Features

- **Show/Hide Password**: Allows users to toggle between showing and hiding their password with a simple click on an eye icon.
- **Real-Time Toggle**: The password visibility is toggled in real-time as users click the eye icon, providing immediate feedback.
- **CSS Styling**: A clean and modern design with visually distinct icons for showing and hiding the password.
- **JavaScript Functionality**: Handles the logic for changing the input type between "password" and "text" to show or hide the password.
- **User-Friendly Interface**: Simple and intuitive controls, making it easy for users to manage their password visibility.
- **Responsive Design**: Works seamlessly across desktop and mobile devices, ensuring that the password toggle functionality is accessible on any screen size.
