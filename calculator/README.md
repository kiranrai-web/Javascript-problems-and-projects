# Calculator JS Project

This is a **Calculator** built using **HTML**, **CSS**, and **JavaScript**. The project allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. It features a simple and intuitive user interface and includes the ability to switch between **Dark** and **Light** themes, providing a customizable experience based on user preference. This calculator is a great example of how to build interactive web applications with JavaScript.

## Features

- **Basic Arithmetic Operations**: Users can perform addition, subtraction, multiplication, and division directly from the calculator's interface.
- **Clear and Reset Buttons**: Includes a "Clear" button to reset the current calculation and a "Reset" button to clear the entire input.
- **Responsive Design**: The calculator adapts seamlessly to different screen sizes, ensuring a smooth user experience on both desktop and mobile devices.
- **User-Friendly Interface**: Clean, easy-to-use layout with clearly labeled buttons for numbers and operations, making the app intuitive for users of all ages.
- **Theme Toggle (Dark/Light Mode)**: Users can switch between a **dark theme** and a **light theme** to match their preferences or improve visibility in different lighting conditions. The theme toggle provides a dynamic and responsive UI.
- **CSS Styling**: Modern and sleek design with a focus on user experience. Buttons are large and easy to click, and the display is clear and readable.
- **JavaScript Functionality**: Uses JavaScript to handle user input, perform calculations, and dynamically update the display.
- **Error Handling**: Displays an error message or prevents invalid operations (e.g., division by zero) to ensure a smooth experience for the user.
