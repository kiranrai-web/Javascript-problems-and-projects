# To-Do List JS Project

This is a simple **To-Do List** application built using **HTML**, **CSS**, and **JavaScript**. The project allows users to create, manage, and track their tasks. Users can add new tasks, mark them as completed, and delete them. This To-Do List app is a great example of how to use DOM manipulation, event handling, and local storage in a web application.

## Features

- **Add Tasks**: Users can add new tasks to the list by entering text and clicking an "Add" button. Each task is added to the list dynamically.
- **Mark Tasks as Completed**: Users can click a task to toggle its completion status. Completed tasks are visually distinct (e.g., with a line through the text or different color).
- **Delete Tasks**: Each task includes a delete button that allows users to remove it from the list.
- **Persistent Storage**: Tasks are saved in **localStorage**, so they persist even after the page is refreshed or the user leaves and returns to the app.
- **Edit Tasks**: Optionally, users can edit the content of an existing task.
- **Responsive Design**: The To-Do List app is fully responsive, providing a smooth experience on both desktop and mobile devices.
- **CSS Styling**: The application is styled with a clean and simple design, making it easy for users to view and manage their tasks.
- **JavaScript Functionality**: Uses JavaScript to handle adding, removing, and editing tasks, as well as updating localStorage to keep the tasks saved between sessions.
