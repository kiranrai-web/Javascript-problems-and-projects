# Popup JS Project

This is a simple **Popup** functionality built using **HTML**, **CSS**, and **JavaScript**. The project demonstrates how to create a modal popup that can be triggered by a button or other event. The popup can be used for various purposes, such as displaying messages, forms, images, or any additional content in an overlay without leaving the current page.

## Features

- **Modal Popup**: A hidden popup that appears when triggered by a button click or other event.
- **Close Button**: Includes a close button (typically an "X" icon) to allow users to dismiss the popup.
- **Background Overlay**: A semi-transparent background overlay that darkens the page content while the popup is open, focusing user attention on the modal.
- **Responsive Design**: The popup is responsive and works well on both desktop and mobile devices, adjusting its size and layout as needed.
- **JavaScript Functionality**: Uses JavaScript to control the opening and closing of the popup, as well as handling user interactions like clicking outside the modal to close it.
- **CSS Styling**: Clean and simple styling for the popup and overlay, with smooth transitions for opening and closing the modal.
- **Multiple Popups**: Option to implement and trigger multiple popups on the same page, with separate content or actions.
