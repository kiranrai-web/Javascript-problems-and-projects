# Weather App JS Project

This is a **Weather App** built using **HTML**, **CSS**, and **JavaScript**. The project allows users to check the current weather for a specified location. It fetches real-time weather data from a weather API (such as **OpenWeatherMap** or **WeatherAPI**) and displays the temperature, humidity, wind speed, and weather conditions. This app provides an easy-to-use interface to check weather information from anywhere in the world.

## Features

- **Search for Any Location**: Users can enter the name of any city or location, and the app will fetch and display the current weather data for that place.
- **Current Weather Information**: The app shows key weather details, including:
  - **Temperature** (in Celsius or Fahrenheit).
  - **Weather Condition** (e.g., clear, cloudy, rainy).
  - **Humidity** (percentage).
  - **Wind Speed** (in km/h or mph).
  - **Weather Icon**: A visual icon representing the current weather condition (e.g., sun, clouds, rain).
- **Real-Time Data Fetching**: The weather data is fetched from an external weather API in real-time, ensuring up-to-date information.
- **Responsive Design**: The weather app is designed to be fully responsive, ensuring a smooth and intuitive user experience on both desktop and mobile devices.
- **CSS Styling**: Clean, modern design with user-friendly components and visual weather icons to make the information easy to read.
- **Search Error Handling**: If a user enters an invalid city or the API fails to fetch data, the app will display an error message to inform the user.
- **JavaScript Functionality**: The app uses JavaScript to fetch data from the weather API, update the UI with real-time information, and handle user interactions.
