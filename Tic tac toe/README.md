# Tic Tac Toe JS Project

This is a classic **Tic Tac Toe** game built using **HTML**, **CSS**, and **JavaScript**. The game allows two players to compete against each other in the traditional 3x3 grid. Players alternate placing X's and O's, with the goal of being the first to align three marks horizontally, vertically, or diagonally. This project demonstrates how to build an interactive game using the DOM and JavaScript event handling.

## Features

- **Single Player Mode**: Add an AI opponent so players can play against the computer. The AI could use simple logic or be made more advanced with random or strategic moves.
- **Interactive Grid**: Click on any empty cell to place an X or O. The game updates the grid in real-time as players make their moves.
- **Win Detection**: The game automatically detects and highlights when a player wins by aligning three marks in a row, column, or diagonal.
- **Draw Detection**: If all cells are filled without a winner, the game will detect a draw and display a message.
- **Reset Function**: After the game ends, users can click a "Reset" button to start a new game, clearing the grid and resetting the state.
- **Simple & Clean UI**: The game has a minimalist design with a clear 3x3 grid, easy-to-click cells, and visible markers (X and O).
- **Responsive Design**: The game is fully responsive and adjusts to different screen sizes, ensuring a smooth experience on both desktop and mobile devices.
- **JavaScript Functionality**: Handles game logic, including player turn tracking, win detection, and resetting the game. The state of the grid is updated dynamically.
