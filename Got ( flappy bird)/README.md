# Got(Flappy Bird Game) JS Project

This is a simple **Flappy Bird** game built using **HTML**, **CSS**, and **JavaScript**. The project replicates the classic Flappy Bird game where players control a bird to fly through pipes, avoiding collisions. The game is interactive and features a scoring system that increases as the bird successfully passes through pipes. It demonstrates how to implement game mechanics using JavaScript and manage game states like starting, scoring, and restarting.

## Features

- **Gameplay Mechanics**: The bird flies upwards when the player clicks or presses a key, and gravity pulls the bird down.
- **Pipes**: Randomly generated pipes that move from right to left, which the player must navigate through.
- **Score Counter**: Keeps track of the player’s score based on the number of pipes successfully passed.
- **Collision Detection**: The game checks for collisions between the bird and the pipes or the ground, ending the game when a collision occurs.
- **Restart Feature**: The game can be restarted after the player loses, allowing for a fresh start without refreshing the page.
- **CSS Styling**: Basic, clean design to create the look and feel of the Flappy Bird game.
- **JavaScript Functionality**: Handles all the logic behind the bird's movement, pipe generation, collision detection, and scorekeeping.
