# Login & Sign Up Form with Smooth Animation JS Project

This is a **Login and Sign Up Form** project built using **HTML**, **CSS**, and **JavaScript**. The project features two forms—one for logging in and one for signing up—along with smooth animations that transition between the forms. The user can toggle between the login and sign-up forms with a sleek animation, providing a user-friendly experience. It also includes basic form validation to ensure that users enter valid data.

## Features

- **Login and Sign Up Forms**: Allows users to choose between a login form or a sign-up form with a toggle button.
- **Smooth Transition Animations**: When switching between the login and sign-up forms, smooth animations provide a seamless user experience.
- **Form Validation**: Validates the input fields for both the login and sign-up forms (e.g., email format, password strength, required fields).
- **Responsive Design**: The layout adapts to different screen sizes, ensuring a consistent experience across desktop and mobile devices.
- **CSS Styling**: Clean, modern design with a focus on usability, ensuring the forms are visually appealing and easy to navigate.
- **JavaScript Functionality**: Handles form toggling (switching between login and sign-up), form validation, and animations to enhance the user experience.
- **Error Messages**: Provides real-time feedback if any required fields are missing or entered incorrectly (e.g., invalid email, weak password).
- **Toggle Between Forms**: Smooth transition effect when toggling between the login and sign-up forms (using JavaScript/CSS transitions).
- **Animated Button Effects**: Buttons for login and sign-up include hover animations to enhance the interactive experience.
