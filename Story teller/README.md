# Story Teller JS Project

This is a **Story Teller** project built using **HTML**, **CSS**, and **JavaScript**. The project generates random stories based on predefined templates or user inputs and then uses AI-powered voice synthesis (via the **Web Speech API** or a similar service) to narrate the story aloud. It’s a fun and interactive way to enjoy random stories, combining text generation with voice synthesis to create a unique storytelling experience.

## Features

- **Random Story Generator**: Generates a random story each time the user clicks a button. Stories are drawn from a collection of templates or pre-written scenarios that are randomly selected and presented.
- **AI Voice Narration**: Uses the **Web Speech API** (or a similar text-to-speech library) to narrate the story aloud. Users can listen to the generated story instead of reading it.
- **Interactive Controls**: Users can start the story, pause it, or skip to the next one with intuitive buttons. The voice speed and pitch can also be adjusted for a personalized experience.
- **Story Display**: The story is displayed in readable text alongside the voice narration, allowing users to read along or simply listen.
- **CSS Styling**: Modern, visually appealing design with text display areas and large, easy-to-read fonts. The interface is user-friendly and visually engaging.
- **Responsive Design**: The interface adapts to both mobile and desktop devices, ensuring a smooth experience on any screen size.
- **JavaScript Functionality**: Uses JavaScript to fetch random stories, display them, and trigger voice narration. It also includes features to pause, resume, and control the narration.
