# Static Website JS Project

This is a **Static Website** built using **HTML**, **CSS**, and **JavaScript**. The project demonstrates how to create a simple, multi-page website with static content, smooth navigation, and dynamic interactive features using basic web technologies. It's perfect for showcasing a portfolio, business site, blog, or informational page.

## Features

- **Smooth Scrolling**: Implemented smooth scrolling for navigation links, enhancing the user experience.
- **Interactive Elements**: JavaScript-powered features like modals, tooltips, or sliders to improve interactivity.
- **Custom Styling**: Beautiful, modern design using **CSS** to create an appealing visual layout.
- **Forms**: Includes basic form elements (e.g., contact form) with client-side validation using **JavaScript**.
- **SEO-Friendly**: Structured with good practices in mind to ensure the website is easily indexed by search engines.
