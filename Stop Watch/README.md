# Stopwatch JS Project

This is a simple **Stopwatch** built using **HTML**, **CSS**, and **JavaScript**. The project provides basic stopwatch functionality, allowing users to start, stop, reset, and track elapsed time. It’s a great example of using JavaScript's `setInterval()` and `clearInterval()` methods to create a time-tracking tool. This stopwatch can be used for various purposes, such as timing activities, workouts, or tasks.

## Features

- **Start/Stop Timer**: Allows users to start and stop the stopwatch with a single button click.
- **Reset Timer**: The user can reset the stopwatch to zero, starting the timer from scratch.
- **Display Elapsed Time**: The stopwatch continuously displays the time in minutes, seconds, and milliseconds.
- **Smooth Transitions**: Time updates are displayed in real-time with smooth transitions, providing a responsive user experience.
- **CSS Styling**: The stopwatch has a clean, modern design with large, readable text to make it easy to see the elapsed time at a glance.
- **Responsive Design**: The layout adapts to different screen sizes, ensuring that the stopwatch works well on both desktop and mobile devices.
- **JavaScript Functionality**: Uses `setInterval()` to update the time and `clearInterval()` to stop the timer when needed.
- **Time Formatting**: The time is formatted with leading zeros for seconds and minutes to ensure a clean, consistent appearance (e.g., "01:03:05" instead of "1:3:5").
