# Digital Clock JS Project

This is a simple **Digital Clock** built using **HTML**, **CSS**, and **JavaScript**. The project demonstrates how to create a live digital clock that displays the current time in hours, minutes, and seconds. The clock updates in real-time, offering a basic example of how to work with JavaScript's `Date` object and implement dynamic functionality.

## Features

- **Real-Time Clock**: Displays the current time, updating every second.
- **CSS Styling**: Stylish and clean design to display the time clearly.
- **JavaScript Functionality**: Uses JavaScript to retrieve and update the current time dynamically.
- **Simple UI**: A straightforward and easy-to-read layout for displaying the time.
