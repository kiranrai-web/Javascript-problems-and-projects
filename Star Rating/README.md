# Star Rating JS Project

This is a simple **Star Rating** functionality built using **HTML**, **CSS**, and **JavaScript**. The project allows users to rate an item (such as a product, service, or content) by selecting a star rating from 1 to 5 stars. The selected rating is dynamically displayed and can be stored or processed for further use, such as sending it to a database or calculating an average rating.

## Features

- **Interactive Star Rating**: Users can select a rating by clicking on one of the stars (from 1 to 5). The stars change color to indicate the selected rating.
- **Hover Effects**: The stars are highlighted on hover, allowing users to preview their rating before selecting it.
- **Dynamic Display**: The number of selected stars is visually represented, and the corresponding rating is displayed to the user.
- **CSS Styling**: Clean and modern design, with customizable star icons and animations to enhance user interaction.
- **JavaScript Functionality**: Handles the logic for selecting a rating, updating the visual display of stars, and capturing the rating value for further use.
- **Real-Time Rating Update**: The rating is updated in real-time as the user clicks on the stars.
- **Reset Option**: Optionally, users can reset their rating by clicking again on the selected star or by using a "Reset" button.
- **Customizable Rating Scale**: Although the default setup is 1-5 stars, the system can be easily customized to work with a different scale (e.g., 1-10).
- **Responsive Design**: The star rating system is fully responsive and adjusts to fit different screen sizes, ensuring a smooth user experience on both mobile and desktop devices.
