# Form Validation JS Project

This is a simple **Form Validation** project built using **HTML**, **CSS**, and **JavaScript**. The project demonstrates how to validate user input in a form, ensuring that the required fields are filled out correctly before submission. It provides real-time feedback to users, helping to improve the form submission process and prevent errors.

## Features

- **Real-Time Validation**: Checks if the form fields are filled out correctly as the user types.
- **Field Validation**: Includes basic validation for fields like text, email, password, and required fields.
- **Error Messages**: Displays custom error messages to guide the user in correcting their input.
- **Submit Button Disable**: The form’s submit button is only enabled once all fields are valid.
- **CSS Styling**: Provides a clean and user-friendly layout with clear error highlighting.
- **JavaScript Functionality**: Validates the form using JavaScript, ensuring proper user input before submission.
