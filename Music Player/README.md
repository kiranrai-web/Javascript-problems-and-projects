# Music Player JS Project

This is a simple **Music Player** built using **HTML**, **CSS**, and **JavaScript**. The project allows users to play, pause, skip, and control the volume of music tracks. It also displays a progress bar to show the current time of the song and includes a playlist feature where users can switch between different songs. The player is designed to provide a sleek, interactive user experience for listening to music directly in the browser.

## Features

- **Play, Pause, and Skip**: Basic music controls to play, pause, and skip to the next or previous track.
- **Volume Control**: Adjust the volume of the music with a volume slider.
- **Progress Bar**: Displays a progress bar to show the current position of the song and allows users to click on it to seek different parts of the track.
- **Playlist**: Allows users to switch between different songs in the playlist, with an easy-to-use navigation system.
- **Song Duration**: Displays the current time and total duration of the song.
- **Autoplay**: The next song automatically starts when the current song finishes.
- **Responsive Design**: The music player is fully responsive, providing an optimal experience on both desktop and mobile devices.
- **CSS Styling**: Modern, minimalist design with clear, user-friendly controls for easy interaction.
- **JavaScript Functionality**: Handles all the logic behind playing songs, controlling the volume, switching tracks, updating the progress bar, and managing the playlist.
