# Toast Notification JS Project

This is a simple **Toast Notification** system built using **HTML**, **CSS**, and **JavaScript**. The project allows you to display small, non-intrusive notification messages (or "toasts") that appear temporarily on the screen. These toasts can be used to inform users about important actions, status updates, or errors, without interrupting their workflow. The toasts automatically disappear after a set duration, providing an unobtrusive way to communicate feedback to users.

## Features

- **Toast Notifications**: Display notification messages that appear in a small box on the screen, usually at the top or bottom.
- **Automatic Dismissal**: Each toast notification automatically disappears after a set duration (e.g., 3-5 seconds), or it can be manually dismissed by the user.
- **Customizable Message Types**: Notifications can have different styles based on their type, such as:
  - **Success**: For successful actions or updates.
  - **Error**: For error messages or failed actions.
  - **Warning**: For warnings or important alerts.
  - **Info**: For general information or status updates.
- **Customizable Positioning**: Toasts can be positioned at the top-right, top-left, bottom-right, or bottom-left of the screen, or anywhere else you'd like.
- **Customizable Duration**: Set how long the toast notification stays visible before automatically disappearing.
- **CSS Animations**: Toasts slide in and out with smooth animations, enhancing the user experience.
- **JavaScript Functionality**: The toast notifications are triggered using JavaScript. You can create new toasts dynamically based on user actions (e.g., submitting a form, saving data, etc.).
- **Responsive Design**: Toast notifications adjust to different screen sizes and will work well on both desktop and mobile devices.
- **Manual Dismiss**: Users can close a toast notification manually by clicking on the close button (optional).
